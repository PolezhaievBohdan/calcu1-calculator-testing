# Інструкція з розгортання у Production

Цей документ описує процес підготовки релізної версії калькулятора та вимоги до середовища користувача.

### 1. Вимоги до апаратного забезпечення
* **Процесор:** x86 або x64 з частотою від 1 ГГц.
* **Оперативна пам'ять:** Мінімум 512 МБ (рекомендовано 1 ГБ).
* **Дисковий простір:** 10 МБ вільного місця.

### 2. Необхідне програмне забезпечення
* **ОС:** Windows 7 SP1, 8.1, 10 або 11.
* **Runtime:** [.NET Framework 4.8 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48).

### 3. Процес розгортання коду (Release Build)
Для створення стабільної версії:
1. Відкрийте проєкт у Visual Studio.
2. Змініть конфігурацію з `Debug` на `Release` на верхній панелі.
3. Виконайте команду **Build -> Build Solution**.
4. Перейдіть у папку проєкту: `calcu1\bin\Release\`.
5. Скопіюйте файл `calcu1.exe` та всі супутні файли `.dll` у цільову папку (наприклад, `C:\Program Files\MyCalculator\`).

### 4. Перевірка працездатності
Запустіть `calcu1.exe`. Програма працює коректно, якщо:
* З'являється графічний інтерфейс користувача.
* Математичні операції (додавання, ділення) виконуються без помилок.
* У папці з програмою не створюється файлів з помилками (якщо не налаштовано логування).
