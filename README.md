# Calcu1 Calculator (WinForms)

Десктопний калькулятор на C# (WinForms, .NET Framework). Має 2 режими:
- "Дві змінних": +, -, *, /
- "Одна змінна": A^2, 1/A, sin, cos, tan, ctn
Також є очищення (C) і пам’ять (->M, M->) та кнопка "Мій інтерфейс".

## Як запустити
1. Відкрити `calcu1.sln` у Visual Studio
2. Натиснути Start (F5)

## Як запустити тести
1. Відкрити рішення у Visual Studio
2. Test → Run All Tests

## Структура проєкту
- `calcu1.sln` — solution
- `calcu1/` — основна WinForms програма
  - `Form1.cs` — логіка інтерфейсу (кнопки)
  - `Form1.Designer.cs` — розмітка форми (UI)
  - `MathFuctions.cs` — логіка обчислень (calc)
  - `Program.cs` — запуск програми
- `calcu1.Tests/` — unit-тести (буде додано)
- `.github/workflows/` — автозапуск тестів на GitHub (буде додано)

## Правила документування коду
Для підтримки високої якості коду в цьому проєкті використовуються XML-коментарі C#.
Будь ласка, дотримуйтесь наступних правил при внесенні змін:
1. **Усі публічні класи та методи** повинні мати як мінімум тег `<summary>`.
2. Якщо метод приймає параметри, обов'язково опишіть їх за допомогою тегів `<param name="...">`.
3. Якщо метод повертає значення, опишіть його в тезі `<returns>`.
4. Якщо метод може викинути виняток (Exception), обов'язково задокументуйте це за допомогою тегу `<exception cref="...">`.
5. Після написання коду переконайтеся, що Visual Studio не видає попереджень щодо відсутньої XML-документації.

## Інструкція для розробників (Onboarding)

Цей розділ допоможе новим розробникам швидко налаштувати середовище та запустити проєкт на "чистій" ОС Windows.

### 1. Необхідне програмне забезпечення
* **ОС:** Windows 10 або Windows 11.
* **IDE:** Visual Studio 2022 (Community, Professional або Enterprise).
* **Система контролю версій:** Git для Windows.

### 2. Налаштування середовища розробки
1. Завантажте та встановіть **Visual Studio 2022**.
2. Під час встановлення у вікні Visual Studio Installer обов'язково оберіть робоче навантаження (workload) **"Розробка класичних додатків .NET"** (.NET desktop development).
3. У панелі праворуч (Деталі встановлення) переконайтеся, що стоїть галочка біля **.NET Framework 4.8 SDK**.
4. Завантажте та встановіть **Git** (з налаштуваннями за замовчуванням).

### 3. Клонування репозиторію
Відкрийте термінал (Command Prompt, PowerShell або Git Bash) у папці, де хочете розмістити проєкт, та виконайте команду:
`git clone https://github.com/PolezhaievBohdan/calcu1-calculator-testing.git`

### 4. Запуск проєкту у режимі розробки
1. Перейдіть у склоновану папку та відкрийте файл рішення `calcu1.sln` подвійним кліком (він відкриється у Visual Studio).
2. Зачекайте кілька секунд, поки Visual Studio завантажить внутрішні залежності (NuGet-пакети для MSTest). База даних для цього проєкту не потрібна.
3. У верхній панелі інструментів переконайтеся, що вибрано конфігурацію **Debug** та платформу **Any CPU**.
4. Натисніть кнопку **Start** (зелений трикутник) або клавішу `F5`.
5. Проєкт скомпілюється, і на екрані з'явиться робоче вікно калькулятора.

### 5. Базові команди розробника (через CLI)
Якщо ви віддаєте перевагу роботі через термінал у корені проєкту:
* **Збірка проєкту:** `dotnet build` або `msbuild`
* **Запуск автоматизованих тестів:** `dotnet test`
* **Генерація документації коду:** `docfx docfx.json` (потребує попередньо встановленого інструменту DocFX: `dotnet tool install -g docfx`)
