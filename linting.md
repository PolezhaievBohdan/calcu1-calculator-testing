# Linting Documentation

## Обраний інструмент
Для аналізу коду використано Visual Studio Code Analysis.

## Причини вибору
- Інтегрований у Visual Studio
- Простий у використанні
- Підходить для C#/.NET проєктів

## Базові правила
- Відступи: 4 пробіли
- Обов’язкові модифікатори доступу
- Використання var
- Попередження про неефективний код

## Як запустити аналіз
1. Відкрити проєкт у Visual Studio
2. Обрати "Аналіз"
3. Натиснути "Виконати аналіз коду"

## Результат
Було знайдено та виправлено більшість проблем коду.
