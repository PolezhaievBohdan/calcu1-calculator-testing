# Інструкція з генерації документації (DocFX)

У цьому проєкті для автоматичної генерації технічної документації та API-довідника використовується інструмент **DocFX**.

## 1. Встановлення DocFX
Оскільки у вас встановлено Visual Studio 2022, найпростіший спосіб встановити DocFX — використати глобальні інструменти .NET CLI.
Відкрийте термінал (або командний рядок) і виконайте:
`dotnet tool install -g docfx`

## 2. Підготовка до генерації
Переконайтеся, що проєкт `calcu1` успішно компілюється, і в налаштуваннях проєкту увімкнено створення файлу XML-документації (Properties -> Build -> Output -> XML documentation file).

## 3. Генерація документації
1. Відкрийте термінал у кореневій папці проєкту (там, де знаходиться файл `.sln`).
2. Виконайте команду ініціалізації базового конфігу (потрібно зробити лише один раз):
   `docfx init -q`
3. Щоб згенерувати документацію та одразу запустити локальний веб-сервер для її перегляду, виконайте:
   `docfx docfx.json --serve`
4. Відкрийте браузер за адресою `http://localhost:8080`. Ви побачите згенерований сайт з документацією вашого API.

## 4. Експорт архіву
Згенеровані файли (HTML, CSS, JS) за замовчуванням зберігаються у папці `_site` в корені проєкту. Для створення архіву просто запакуйте цю папку у `docs_archive.zip`.
