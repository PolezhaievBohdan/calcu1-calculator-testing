# Резервне копіювання

Оскільки проєкт не використовує зовнішню СУБД, стратегія резервного копіювання зосереджена на збереженні вихідного коду та стабільних релізів.

### 1. Резервне копіювання вихідного коду
* Весь код зберігається у репозиторії GitHub. 
* **Частота:** При кожному логічно завершеному етапі розробки (Push).
* **Локальний бекап:** Рекомендовано мати копію папки проєкту на зовнішньому носії.

### 2. Резервне копіювання релізів (Artifacts)
* Кожна стабільна версія (Release build) повинна бути заархівована (ZIP).
* Архів зберігається в розділі **GitHub Releases** для можливості швидкого відкату.
